# Shyxzz Sites

Site institucional em HTML, CSS e JavaScript.

## Estrutura

- `index.html` — página inicial
- `servicos.html` — serviços
- `processo.html` — processo de trabalho
- `portfolio.html` — portfólio
- `solicitar.html` — formulário integrado ao WhatsApp
- `contato.html` — contatos e redes sociais
- `assets/css/style.css` — estilos
- `assets/js/main.js` — menu e integração com WhatsApp

## Como publicar

Envie os arquivos para sua hospedagem ou use qualquer serviço de hospedagem estática.

O WhatsApp configurado é `(24) 98130-0648`.

No formulário, ao enviar, o WhatsApp abre uma conversa com os dados preenchidos.
O visitante precisa confirmar o envio no WhatsApp.

## Observações

- Substitua os placeholders do portfólio quando tiver trabalhos.
- Os arquivos podem ser usados em hospedagem estática.
- É necessário conectar um domínio ao seu provedor de hospedagem.
